1.3 Project Export and Import Operations
=========================================

Exporting Your Project
-----------------------

Once you've completed your programming work, modify the project title and description as needed, then select the **Download** option to export your project for local storage or distribution.

.. image:: ../img/Save_import_pipermake1.png

Specify your desired filename and click the **Download** button once more to export your project as a ``.png`` file format.

.. image:: ../img/Save_import_pipermake2.png

.. _import_code_piper:

Loading Existing Projects
--------------------------

From the Piper Make `main interface <https://make.playpiper.com/>`_, select **Import Project**.

.. image:: ../img/Save_import_pipermake3.png

Browse to locate the ``.png`` file within the ``Ultimate-Starter-Kit-for-Pico-W\Piper_Make`` directory and proceed with **Import**. 
Ensure you have first obtained the `Ultimate-Starter-Kit-for-Pico-W <https://github.com/lafvintech/Ultimate-Starter-Kit-for-Pico-W/archive/refs/heads/main.zip>`_ package.
Alternatively, access the repository directly at `Ultimate-Starter-Kit-for-Pico-W - GitHub <https://github.com/lafvintech/Ultimate-Starter-Kit-for-Pico-W>`_.

.. image:: ../img/Save_import_pipermake4.png

Your imported project will now be visible and accessible within your workspace.

.. image:: ../img/Save_import_pipermake5.png
